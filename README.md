# signals-core
Библиотека предметной логики

## Назначение и состав
Репозиторий содержит библиотеку классов с предметной логикой для работы с одноканальными сигналами (хранение, фильтрация, анализ диапазона, чтение и запись файлов). Библиотека не зависит от пользовательского интерфейса.

Состав репозитория:
- `SignalProcessing.Core.sln` — файл решения;
- `SignalProcessing.Core` — проект библиотеки классов (Class Library).

## Требования
- Целевая платформа: **.NET Framework 4.8**

## Связанные репозитории
Библиотека используется приложением WPF из репозитория:
https://github.com/baldakrut/signals-generator-app

Библиотека `SignalProcessing.Core` собирается самостоятельно, без наличия репозитория приложения.

Для совместной работы и сборки приложения оба репозитория необходимо клонировать в один общий родительский каталог, рядом друг с другом, под их исходными именами:

C:\Project\
	signals-core\
	signals-generator-app\
